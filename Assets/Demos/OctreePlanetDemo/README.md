# Octree Planet Demo

Reference implementation from [test-octree-planet-terrain-unity](https://github.com/PaperPrototype/test-octree-planet-terrain-unity).

**Scene:** `Assets/Scenes/OctreePlanetDemo.unity`

**Controls:** WASD + mouse (LookAround). Fire3 (Shift?) for faster movement.

**Components:**
- Octree — octree LOD for spherical planet
- LookAround — first-person camera controller
- ChunkPrefab — mesh template for leaf nodes
